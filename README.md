# 光影票务 · 电影票售票系统（Java Swing 演示）

基于 **JDK 24 + 纯 Java Swing** 的电影票售票系统桌面演示。遵循课程作业要求，
**未使用 SSH / SpringBoot 等任何框架**，界面全部由 Swing 自绘组件搭建；
数据为内存 Mock，不依赖真实数据库、网络或支付。

## 功能特性

### 顾客端

- **登录 / 注册**：回车直接提交，字段级红框校验，逐项提示缺失信息
- **首页**：主视觉自动轮播（5.5s 间隔、悬停暂停、左右箭头、缩略图与指示点）、
  类型九宫格筛选、正在热映 / 即将上映 / 经典重映三档分区、小食展示
- **影片详情与选座**：座位图悬停高亮与状态提示（可选 / 已售 / 已选择）、
  点已售座或超 6 座上限有行内红字反馈、右侧栏实时显示已选座位与合计金额
- **购物车 / 结算**：加入购物车、模拟支付、会员折扣自动计算
- **我的订单**：未支付订单可直接「去支付」，支持取消与查看明细
- **我的会员**：5 档会员体系（普通 / 银卡 / 金卡 / 铂金 / 钻石），
  等级由累计消费自动升级、只升不降，展示权益对比与升级进度

### 管理端

- 顾客、影片、影厅、场次、订单五个模块
- 侧栏模块高亮与指示条、表格空状态、搜索过滤
- 支持新增 / 编辑顾客（含手动定档）、影片、影厅与排片

## 运行

```bash
mvn package
java -jar target/movie-ticket-demo-1.0.0.jar
```

> 需要 JDK 24 及以上（Swing 为 JDK 自带，无需额外依赖）。

## 测试

```bash
mvn test
```

共 74 个单元 / 交互测试，覆盖业务规则（会员升级、消费统计）、
界面交互（回车提交、导航选中态、座位命中精度）与渲染冒烟。

## 项目结构

```
src/main/java/com/movieticket/
├── demo/       # 演示数据服务（内存 Mock，含业务规则与异常）
├── model/      # 领域模型（record）：影片、订单、座位、会员等级等
└── ui/
    ├── MovieTicketDemoApp.java   # 程序入口（JFrame + CardLayout）
    ├── component/                # 自绘组件：主题 Ui、座位图、主视觉轮播等
    └── screen/                   # 页面：登录、顾客端、管理端
database/         # 关系库 schema 与种子脚本（课程附录，程序本身未接库）
```

## 设计说明

- 主题色与样式集中在 `ui/component/Ui.java`，全项目无散落的硬编码颜色
- 等级由 `MembershipLevel.forSpending(累计消费)` 唯一推导，`payOrder`
  出票后自动结算升级，前端无任何直接改档入口
- 交互基建可复用：导航选中态（`Ui.NavSelection`）、表格空状态（`Ui.TableCard`）、
  行内提示（标签变红 + 定时恢复，不打断操作）
